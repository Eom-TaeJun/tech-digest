## ⚙️ AI 기법 & 아키텍처

**에이전트 오케스트레이션**
- **Hub-and-Spoke가 프로덕션 표준**: 중앙 오케스트레이터 + 전문 스포크 에이전트 구조. 스웜 대비 비용 80% 절감, 무한루프 방지. CrewAI, AutoGen v0.4가 대표 구현체(각각 22k, 28k stars).
- **스웜(Swarm)은 프로덕션 부적합**: 에이전트 10개 초과 시 조율 비용 폭증, "데모용"이라는 커뮤니티 합의. `@karpathy`: "에이전트에는 킬스위치가 반드시 필요하다."
- **MCP(Model Context Protocol) 급부상**: 신규 에이전트 레포의 ~40%가 MCP 언급. 공유 컨텍스트 비용 60% 절감, 벡터 DB 대비 구조화·버전관리 우위. `mcp-server` 레포 8k stars.

**프롬프트/컨텍스트 최적화**
- 소형 모델로 API 호출 80% 처리 → 대형 모델은 복잡 추론에만 사용 = **컴퓨팅 비용 70% 절감**.

- 캐싱·배치·스로틀링 조합으로 **추가 30~70% 절감** 가능.
- 프롬프트는 "산문 설명" 대신 **JSON 스키마·실제 예시 2~3개** 방식이 효과적. 프롬프트를 코드처럼 버전 관리하는 관행 확산.
