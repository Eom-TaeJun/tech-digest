## ⚙️ AI 기법 & 아키텍처

### CLAUDE.md / 에이전트 메모리 패턴
- **핵심 3파일 구조**: `CLAUDE.md`(앱 메모리·일일 요약) + `roadmap.md`(스프린트 계획) + `handoff.md`(세션 인계) — 세션 시작/종료 시 업데이트
- **컨텍스트 관리 원칙**: 대화 기록·도구 결과는 인라인이 아닌 외부 파일로 오프로드; 메인 에이전트 컨텍스트를 최소화
- **다중 에이전트 분리**: 토큰 집약적 서브태스크는 전문 서브에이전트에 위임 후 요약만 수신 → 컨텍스트 오염 방지
- **실패 패턴**: 프롬프트에 100개+ 도구 나열, 거대 단일 에이전트, LLM 자동 평가 먼저 시작(수동 레이블링 20건 먼저 해야 실패 패턴 파악 가능)

### MCP (Model Context Protocol) 실전 현황
- **Azure Logic Apps + MCP**: Dynamics 365 등 엔터프라이즈 앱을 에이전트 호출 가능 툴로 노출 — 오케스트레이션 복잡도 대폭 감소
- **Google MCP Toolbox (Java SDK)**: AlloyDB·Spring Boot와 연동, HTTP 세션 기반 상태 유지 — 트랜짓 예약 등 상태 기억 필요한 에이전트에 적합
- **보안 경고**: 툴 체이닝 시 의도치 않은 액션 발생 위험(예: 원장 조회 → 자금 이체); 내장 인증 없어 Okta 등 외부 ID 플레인 필수
- **`datagouv/datagouv-mcp`**: 프랑스 공공 데이터셋을 Claude/ChatGPT/Gemini에 노출하는 경량 govtech 사례

### 비용 절감 기법 (수치 포함)
| 기법 | 절감 효과 | 핵심 포인트 |
|------|-----------|-------------|
| 프롬프트 캐싱 | 토큰 75% 절감, 비용 50% 감소 | 정적 시스템 프롬프트에 효과적 |
| LLMLingua 컨텍스트 압축 | 토큰 60~80% 감소 | RAG 레이턴시 40% 개선 동반 |
| 신뢰도 기반 라우팅 | 비용 70~90% 절감 | 70% 미만 신뢰도 시 상위 모델로 에스컬레이션 |
| 배치 처리 (32~128건) | 비용 50%+ 절감 | JSONL + 구조화 출력 병행 시 극대화 |
| RAG vs 롱컨텍스트 | RAG가 5~10배 저렴 | 128k+ 토큰 직접 입력 대비 |

### 신규 기법 (2026 등장)
- **Context Engineering**: 시스템 지시(고정)와 사용자 프롬프트(동적)를 구조적으로 분리 — 기존 "모놀리식 프롬프트"의 포커스 손실 문제 해결
- **DR-CoT (Dynamic Recursive CoT)**: 재귀적 서브문제 분해 + 동적 컨텍스트 프루닝 → BERT급 소형 모델로 GPT-4 GPQA Diamond 3~4pt 초과
- **CISC (Confidence-Informed Self-Consistency)**: 다수결 투표 대신 신뢰도 가중 경로 선택 → GPT-3.5-turbo 기준 +4.44% 향상
